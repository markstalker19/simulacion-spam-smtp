# Simulación de envío de correos mediante SMTP
Proyecto desarrollado con fines exclusivamente académicos y educativos para practicar el funcionamiento del protocolo SMTP y el envío automatizado de correos electrónicos.

La aplicación permite enviar mensajes a diferentes destinatarios, simulando el funcionamiento de una campaña de correo SPAM en un entorno controlado. El objetivo es comprender cómo se estructura y realiza el envío de correos mediante SMTP y reforzar los conocimientos adquiridos durante el desarrollo.

Este proyecto no está destinado al envío de SPAM real, al abuso del servicio de correo, al envío masivo no autorizado ni a ningún otro uso malintencionado. Su finalidad es únicamente educativa y de aprendizaje.

Por motivos de seguridad y privacidad, las direcciones de correo y demás datos utilizados en el proyecto han sido modificados y no corresponden a destinatarios reales.

## Objetivos
·Practicar el funcionamiento del protocolo SMTP.

·Aprender a enviar correos electrónicos mediante código.

·Trabajar con diferentes destinatarios.

·Comprender la estructura de un mensaje de correo electrónico.

·Simular el funcionamiento de un sistema de envío de correos en un entorno controlado.

·Aplicar buenas prácticas de seguridad y privacidad.

### Finalidad
Este proyecto forma parte de mi proceso de aprendizaje y tiene fines exclusivamente académicos. No debe utilizarse para realizar envíos no autorizados, SPAM real o cualquier actividad que pueda perjudicar a terceros.
